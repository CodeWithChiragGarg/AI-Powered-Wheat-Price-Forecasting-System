# ⚡ SYSTEM OVERVIEW

An advanced **Power BI-based environmental analytics system** engineered to transform raw pollution datasets into actionable visual intelligence.

The dashboard analyzes:
- AQI fluctuations
- PM2.5 & PM10 concentration
- Urban pollution patterns
- City-wise environmental trends

using interactive KPI-driven visualizations.

```text
◉ AQI Trend Intelligence

◉ Visual Data Exploration
```
