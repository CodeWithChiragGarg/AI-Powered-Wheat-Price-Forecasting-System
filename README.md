AI-Powered Wheat Price Forecasting System

Machine Learning-based forecasting system developed using real mandi data from AGMARKNET to predict future wheat prices using Linear Regression and Random Forest algorithms.

✨ Features
- Real mandi wheat price analysis
- Data preprocessing and cleaning
- Future wheat price prediction
- Yearly forecasting
- Linear Regression model
- Random Forest Regressor
- MAE-based model evaluation
- Data visualization using Matplotlib

🛠️ Tech Stack
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

📊 Models Used
- Linear Regression
- Multiple Linear Regression
- Random Forest Regressor

📈 Evaluation
- Linear Regression MAE ≈ 7.77
- Random Forest MAE ≈ 2.88

🎯 Objective
To help farmers and traders analyze future wheat price trends using historical agricultural market data.
